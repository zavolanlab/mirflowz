# <kbd>script</kbd> `trim_id_fasta.sh`

Trim the sequence ID of a FASTA file to the first white-space.

Usage
-----

```bash
bash trim_id_fasta.sh input_file
```

Arguments
---------

- <b>`$1`</b> | <b>`input_file`</b> (string): path to the input FASTA file

Exit codes
-----------

- <b>`0`</b>: If successful
